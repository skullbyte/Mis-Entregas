## Cómo ejecutarla
Versión web (sin instalar nada): https://skullbyte.github.io/Mis-Entregas/

En el ordenador:
1. Instalar Flutter.
2. `flutter pub get`
3. `flutter run -d linux`

## Estructura
- `lib/pages/`: las tres pantallas.
- `lib/models/`: la clase Tarea.
- `lib/globals/`: el estado, el router y el tema.
